## Run 1 (before tuning)

All 22: success 13 -> 14, median time 62 s -> 62 s (1.00x), median turns 27 -> 14, cost $5.61 -> $4.38. Time inside fastb: 42% of the total (median 21 s per task).

Fixes between run 1 and run 2 (found by reading the transcripts):
- Settle treated any visible progressbar as loading. Staynb shows rating bars as progressbars with values, so every action waited the full 3 s. Now only progressbars without a value count.
- A gone ref waited 5 s; now 0.5 s (a ref is there or gone for good).
- A covered click waited 5 s and said only "covered". Now 3 s, and it names the covering panel by its text.
- `fill` on a `<select>` now selects; on other non-text elements it stops with a hint.
- Icons inside one clickable box (GoMail "Mark as read · Snooze · Add to tasks") get their own refs; click targets also match aria-label.
- Skill: no screenshots (the agent cannot open them in this setup).

## Caveats

- One run per task per setup. Single runs vary; the 1.51x is just over the 1.5x checkpoint. Phase 7 runs each task 3 times.
- Turns and cost fall clearly in both runs; time depends on fastb's own waits.
